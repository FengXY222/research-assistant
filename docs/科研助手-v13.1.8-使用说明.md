# 科研助手 v13.1.8 使用说明

v13.1.8 修复成果子标签绕过主窗口导航导致页面长期停留在“正在准备成果”的问题。所有子标签现在统一由主窗口完成首次加载、失败恢复和后续复用。

每日前沿、期刊库、特刊征稿与成果页面之间改为直接切换，不再对整个复杂页面执行透明度动画；小型弹窗仍保留轻量动画，并会在结束或中断后释放对象。

特刊刷新在大型正式库中使用 SQLite 增量通道：失败来源按分片保存，只读取本轮新记录、可能冲突的旧记录和当前待补 AI 评分记录，不再把完整特刊库加载和复制到内存。取消或异常后保留来源与分片检查点，下次可幂等续跑。

软件只在空闲时执行自动备份、数据库维护和后台补全。检测到鼠标、键盘或滚轮操作后，会安全中断正在运行的后台任务；每日前沿、特刊和期刊补全保留可继续处理的状态。

备份复制与 SHA256 校验采用固定大小分块流式处理，不再把数据库整文件读入内存。自动备份继续只保存 `research_assistant.sqlite` 与必要配置，不包含可重建的 `research_intelligence.sqlite` 网络缓存。

用户数据默认位于 `%LOCALAPPDATA%\科研助手\UserData`。升级安装不会删除该目录，也不会把个人数据打入发行目录或安装包。

## 13.1.8 独立 PDF 翻译

侧栏文献下方新增工具，进入工作中的工具页。添加 PDF 后一次翻译一篇，其余排队；可单独设置翻译服务。取消先通知异步任务，超时后清理本次任务的进程树。中断保留参数，重试复用译文缓存。切换页面不会取消手动任务。

本安装包自带独立 Python 3.12 翻译环境，不依赖系统 Python；主软件全局 API 限流、AI 开关和空闲任务取消不控制它。默认并发 2、独立速率 2 次/秒；模型及字体首次翻译需要联网下载。输入文件不覆盖，输出存入用户数据目录 pdf-translator/results。

全文测试翻译进程峰值约 3.23 GiB，结束后释放；少量复杂表头、公式和短文本仍需对照原文检查。更新安装不会替换用户业务数据。详细测试见 PDF翻译组件接入与样机测试.md。
