# 科研助手 v13.1.2 使用说明

## 本版设置入口

点击主窗口顶部“设置”后，可直接在一级页面中编辑：

1. **通用设置**：外观密度、窗口与导航、开机自启、托盘行为、快捷键、每日前沿后台更新、备份与数据位置。
2. **增强服务**：DeepSeek、Clarivate JCR、EasyScholar，以及每日前沿/特刊的全部数据来源与 API Key。

密钥仍只保存在当前 Windows 用户账户中；留空时保留旧密钥，勾选“清除”才会删除。

## 四个工作台

科研助手仍以四个工作台组织日常工作：概览、工作、论文和文献。概览中的“今日下一步”继续聚合待办和研究进度。

## 每日前沿

- 研究设置从每日前沿的“…”菜单直接打开，不经过全局设置二次跳转。
- 结果保留内容相关度与科研价值双轴；AI 内容相关性分是增强项，没有 AI 时仍使用本地双轴评分。
- 低权重探索只参与动态回补，不会因为数量不足而强行推送低质量论文。

## 期刊库与特刊征稿

- 期刊库顶部“新增”可直接添加期刊；“选刊”用于打开论文选刊工作台。
- 期刊库“…”仅保留 JCR、EasyScholar 与 DeepSeek 三类明确增强操作。
- 特刊征稿仍支持多来源发现、收藏、核验、关联论文、加入投稿路径与创建准备任务。
- 扫描版 PDF 仍可使用本地 OCR 提取文字后参与画像与选刊。

## 窗口与数据

开启“仅最小化不退出”后，点击关闭按钮只会收起到系统托盘。数据默认保存于 `%LOCALAPPDATA%\科研助手\UserData`，设置中可创建备份或迁移到其他目录。
