# 科研助手 v13.1.1 使用说明

科研助手是本地 Windows 科研工作台。主界面分为概览、工作、论文和文献四组；复杂任务在独立工作台中完成。

## 1. 基本使用

- 每个页面只保留一个主要操作；低频功能位于“…”菜单。
- 遇到筛选、证据或评分详情时，先查看系统给出的结论，需要时再展开。
- 程序使用“雾青蓝”主题，可在设置中心调整舒适或紧凑密度。

## 2. 每日前沿

点击“更新”执行多来源发现、事实初筛、双轴评分、可选 AI 调整和动态推荐。卡片首屏用于回答三件事：论文是什么、为什么推荐、下一步做什么。

- “打开原文”：查看论文来源页面。
- “加入待读”：保留到待读清单。
- 卡片“…”：查看评分与来源、标记已读或相关、填写一句话评价、忽略论文。
- 页头“…”中的“切换列表”：查看待读、已读、优先期刊和历史记录。

未读保留开启时，未处理论文次日继续留在每日前沿；关闭时删除内容但保留去重指纹。没有配置 AI 时，本地规则仍可正常评分与推荐。

## 3. 特刊征稿

工作台左侧是候选特刊，右侧优先显示推荐结论与征稿范围。

- 首行可直接搜索；出版社、费用、分区、截止时间和匹配论文位于“筛选”。
- “添加个人判断”用于记录适合稿件和风险；“核验依据”用于查看 ISSN、官网与第三方来源。
- 底部可收藏特刊、选择论文并加入投稿路径；已读、入库、关联、创建任务和排除位于“…”中。
- 没有匹配结果时，详细编辑区自动隐藏；放宽筛选即可恢复候选。

## 4. 为论文选刊

从投稿记录页发起“为论文选刊”。系统先从期刊库与相似论文召回候选，再按契合度和投稿策略双轴排序。明确停刊、文章类型客观不符、已拒稿或永久排除才硬删除；未知信息默认降低置信度。

## 5. 设置与数据

设置中心包含外观、通用与数据、AI 服务、研究画像和期刊工具。所有可配置 Key 的来源集中在 AI 服务中，本机加密保存；所有外部 API 共用每秒最多 5 次的限速。

正式数据默认位于 `%LOCALAPPDATA%\科研助手\UserData`。覆盖安装不会主动删除个人数据；更新任务支持错过补跑、成功不重跑、失败来源重试和崩溃后续跑。
