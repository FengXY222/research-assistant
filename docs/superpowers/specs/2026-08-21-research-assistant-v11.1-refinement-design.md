# 科研助手 v11.1 精修设计

## 目标

在保留现有“小组件 + 软件模式”布局与本地 JSON 数据结构的前提下，消除设置卡顿，减少 HOME 信息重复，并将选刊和期刊分区数据变成可解释、可追溯、不会覆盖人工记录的工作流。

## 已确认的产品决定

- 主题色不再通过每次替换全局 QSS 实现；使用 Qt `QPalette` 切换色彩，QSS 仅在信息密度变化时重建。
- 新增朱砂米、紫藤暮、夜航朱三套跨色相主题，保留雾青蓝为默认主题。
- HOME 的今日任务直接展示最多三项未完成任务；“待推进”只放论文/回复动作；“投稿观察”不再重复任务截止。
- HOME 的论文动作携带 `paper_id` 与 `journal_id`，进入 PAPERS 后自动展开并短暂高亮对应期刊记录。
- WORK 的优先级操作为“点击选择 + 长按专用按钮拖动”，不再对整条任务意外触发覆盖层；拖放框为靠近按钮的小型四象限浮层。
- 拒稿归档收纳为 PAPERS 标题栏角落按钮，点击后以独立紧凑窗口查看。
- LIBRARY 的默认锚点为每日前沿。

## 选刊工作台

1. 输入必须以论文题目、关键词和摘要为核心。摘要为空时明确提示，而不是假装有足够依据。
2. 设置项包括：公开获取（不限/偏好/必须）、目标分区（不限/Q1/Q1–Q2/允许未知）、三四区过滤、投稿时效优先（关闭/适中/高）。
3. DeepSeek 是首要适配评分来源：AI 匹配度 0–70；本地、已核验信息最多补充 30 分。无模型密钥时保留标注清晰的本地备选排序。
4. AI 可以返回“库内候选”和“外部候选”；外部候选清楚标为“待入库/待核验”，不会自动写入投稿记录。用户可点击“快速入库”，随后才可加入投稿路径。
5. 期刊分区、开放获取、时效等未知值只显示为待核实，不伪造事实；“时效优先”仅依据模型返回的区间和置信度形成附加分。

## EasyScholar 数据层

- 设置中新增 EasyScholar 开放接口密钥，使用当前 Windows 用户 DPAPI 加密保存；为空或关闭时绝不发起请求。
- 数据更新只查询新建、改名、缺失或过期（默认 30 天）记录；稳定记录跳过，避免浪费接口额度。
- 解析并保存 JCR 分区、中科院基础版/升级版、影响因子、五年影响因子、EI/ESCI 等可用字段，并带 `source`、`checked_at`、查询签名。
- 数据优先级：用户锁定/手动 > Clarivate 已核验 > EasyScholar 已核验 > DeepSeek 估计 > 未知。来源冲突保留双方数据，不静默覆盖。
- 当 EasyScholar 返回已核验 Q3/Q4 且用户开启默认过滤时，每日前沿和选刊都将过滤该候选；未知分区仍可显示。

## 数据与验收边界

- 所有自动化测试使用 `RESEARCH_ASSISTANT_DATA_DIR` 临时目录；正式安装目录仅做只读一致性检查。
- 真实数据中既有论文、期刊、成果、附件和密钥字段必须保持可读取；新增字段应向后兼容。
- 发布前执行全量 pytest、编译检查、主题耗时对比、不同窗口宽度截图审查，以及安装升级数据哈希验证。
