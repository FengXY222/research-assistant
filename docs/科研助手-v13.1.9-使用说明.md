# 科研助手 v13.1.9 使用说明

本版本整合六批次、17项审查修复，保留 v13.1.8 的统一导航、SQLite 业务库、独立 PDF 翻译和既有科研筛选策略。

## 主要更新

- 每日前沿按记录保存用户操作，拒绝过期快照；刷新结果及运行状态原子提交。
- 保存失败会提示并提供“重试保存”，失败未解决时不会自动关闭软件。
- 备份完成并校验后才作为有效备份；临时数据库锁不会误判为损坏。
- 普通页面操作仅暂停空闲任务，不误取消手动更新或手动PDF翻译；暂停保留续跑检查点。
- 成果、前沿、投稿记录、灵感和待读采用可见区域卡片；期刊库数据库分页读取。
- 词典翻译优先命中，模型按需加载并闲置释放；缓存改为批量事务写入。
- 未展示前沿候选独立保存在业务库；联网更新保留小型诊断摘要。
- PDF翻译任务库纳入备份和数据目录迁移，备份不携带接口密钥；是否备份输出PDF由工具页设置。
- 自定义AI接口不默认携带特定服务商参数；锁定构建依赖并精简允许范围内的翻译运行时资源。

## 安装与数据

退出旧版本后运行安装包。安装程序不包含个人业务数据、API密钥或本地翻译缓存；原用户数据继续保留。升级前建议保留一份有效备份。恢复翻译设置后需要重新填写密钥。

## 独立 PDF 翻译

工作 → 工具 → PDF翻译。一次处理一个文档，其他任务排队。手动翻译不受主应用空闲任务规则影响。取消先请求异步任务停止，超时后清理本次进程树；中断任务保留参数，重试可利用翻译缓存。

## 验证边界

代码回归使用正式数据隔离副本和模拟异常。实际网络来源、收费AI全文翻译和此前空前沿的根因不能仅由本地测试确认。分块备份校验、页面切换和长列表测量详见 [17项验收结果](全项目17项修复验收结果-20261002.md)。网络取消为协作式，单次请求可能等待其超时才结束。
