- 主构建使用 `requirements-build.lock`；便携翻译运行时只裁剪白名单内的测试资源及字节码缓存，保留图像、数学、模型及 Web UI 必需依赖。
- 隔离构建的运行时位于 `.test-results/repair-20261002/portable-runtime`。site-packages 由约943.82 MiB降至715.09 MiB，约减少228.73 MiB（24.23%）。这是运行时目录大小，不是最终压缩安装包大小。
- 运行时核心导入及 `pdf2zh_next.high_level` 异步入口探针通过；用户提供PDF能读取15页。没有在裁剪后重新完成一次收费AI全文翻译，也没有新安装器、安装启动和最终发行哈希验收。
- 翻译任务库纳入在线备份，备份密钥清空并清除残余页；结果PDF是否纳入备份由用户开关决定。迁移保留外部原文路径，只重写组件内部结果路径。

## 剩余验证与注意事项

1. 每日前沿此前为何为空仍没有证据定论。下一次真实联网刷新将保存统计摘要、来源结果与AI诊断，不能把代码修复等同于已找回论文。
2. 自定义AI参数、取消、失败恢复有模拟和隔离验证；未逐一在线验证所有API、所有出版社和全来源补跑。已有成功来源不重跑逻辑由既有回归保护。
3. 取消是协作式：单次阻塞网络请求可能到超时才结束（发现请求约20秒、AI请求约45秒），页面切换不会同步等待该请求；不声称网络请求能瞬间强制结束。
4. 同日、同输入暂停批次可恢复；日期或输入变化可新建批次并利用缓存，不保证跨日恢复旧批次。保留批次数有上限，避免再膨胀。
5. 冷启动首次模块加载、显式批量编辑及大数据排序仍有成本。短时间CPU上升不等于泄漏；本轮稳定切换未出现持续内存/控件增长。
6. 闲置模型释放的实际大模型内存变化、备份完整恢复到另一台电脑、断电中断，以及最终发行包真实翻译仍需发布前专项验收。
7. 模块拆分为渐进方式，前沿和特刊的大函数并未全部重写；保留被测试及历史兼容引用的旧入口，未进行盲目删模块。
8. 缓存论文默认90天、验证缓存30天清理；业务候选不随缓存TTL删除。本轮未手动清理或压缩正式数据库，规则在后续空闲维护时执行。
