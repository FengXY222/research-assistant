# 科研助手 v13.1.5 使用说明

v13.1.5 延续现有的通用设置、增强服务、每日前沿、期刊库、特刊征稿和选刊逻辑，并完成大型业务数据的 SQLite 迁移与界面性能优化。

每日前沿、期刊库和特刊征稿会先显示已有结果，再在后台检查更新。页面切换不会同步执行整库读取、评分和控件重建。

期刊库使用虚拟列表，仅绘制当前可见记录。双击期刊可编辑，右键可收藏、更新资料或删除。v13.1.5 修复了浅色主题下期刊卡片错误显示为深灰色的问题。

特刊、每日前沿、期刊资料、评分和任务运行状态保存在统一的 SQLite 数据库中。旧版大型 JSON 数据首次迁移后会保留归档，窗口尺寸、主题、API 地址等小型设置仍使用 JSON。

自动备份、每日前沿、期刊增强与特刊检查会尽量在软件空闲时运行。数据默认保存于 `%LOCALAPPDATA%\科研助手\UserData`，升级安装不会删除该目录或已有备份。
