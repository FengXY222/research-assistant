# 科研助手 v13.1.0 更新说明

发布日期：2026-09-18

v13.1.0 是一次前端整理版本，不改变 v13.0 已确认的每日前沿、特刊征稿和为论文选刊业务规则。重点是降低界面厚重感、突出主要动作，并把分散的设置入口收拢为一处。

## 主要变化

- 主题收敛：只保留“雾青蓝”主题。旧配置中的其他主题编号会自动映射到该主题，用户数据不受影响。
- 彩色功能区：每日前沿为蓝、期刊库为绿、特刊为橙、投稿为紫、成果为青、任务为琥珀、灵感为粉。
- 共享页面框架：八个主页面统一使用单行页头、主按钮和“…”次要操作菜单；列表页统一搜索、筛选和计数布局。
- 导航更新：四工作台结构保持不变，侧边栏由竖排英文改为图标＋中文；组内标签使用与功能区一致的选中强调色。
- 设置中心：新增“外观 / 通用与数据 / AI 服务 / 研究画像 / 期刊工具”五分区。顶栏设置、前沿研究设置和期刊库数据工具均可直达对应分区。
- 兼容策略：大型研究画像、选刊和特刊工作台继续使用独立窗口；原有类保留为兼容外壳，既有数据格式和后端任务链不变。

## 业务逻辑保持不变

- 每日前沿仍执行六种召回、事实初筛、相关度/科研价值双轴评分、可选 AI 有限调整和动态金字塔展示。
- 特刊仍按来源分片、失败来源补跑、完整后提交；缺少完整范围时可从标题与其他信息推断，但缺关键展示信息的记录不推送。
- 选刊仍执行统一硬门槛、双轴评分和冲刺—主投—稳妥—探索分层；AI 未配置时，本地规则评分照常工作。
- 所有外部 API 继续受全局每秒最多 5 次调用限制。

## 升级提示

可直接覆盖安装 v13.0。正式数据位于用户数据目录，安装和卸载不会删除科研数据；升级前仍会按现有机制创建备份。
