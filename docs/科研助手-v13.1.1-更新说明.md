# 科研助手 v13.1.1 更新说明

发布日期：2026-09-18

本版本修正 v13.1.0 只统一视觉、却没有真正减少信息的问题。业务规则、数据和后台任务机制保持不变，默认界面改为“先看结论，再按需展开依据”。

## 每日前沿

- 卡片默认只显示论文标题、期刊与日期、相关度/科研价值摘要、推荐理由。
- 默认动作只保留“打开原文”和“加入待读”；已读、相关、评价、忽略、评分构成与发现来源收进“…”菜单。
- A/B/C 层级、AI 是否参与、期刊偏好分和详细分区不再同时堆在卡片首屏。
- 八种列表视图收进页头“…”菜单；空状态只显示一句结果。
- 更新完成后的进度条自动收起，旧缓存提示改由更新按钮文字和提示承载。

## 特刊征稿工作台

- 搜索保留在首行，画像、出版社、费用、JCR、中科院分区和截止时间筛选默认折叠。
- 没有结果时，只显示简洁空状态，不再展示空白征稿范围、笔记框和不可用操作。
- 有结果时优先显示期刊、截止、相关与投稿机会、推荐理由和征稿范围。
- 个人判断与核验依据按需展开；收藏、论文选择、加入投稿路径和低频操作合并为一排。

## 验证

- 新增渐进展示与空状态回归测试。
- 使用 480×720 和 1024×768 离屏渲染检查文字裁切、控件越界与重叠。
