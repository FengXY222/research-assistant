# 科研助手 v12.1 使用说明

科研助手 v12.1 是 v12.0 的稳定修复版，保留小组件模式与原有本地数据位置。

## 本版重点

- 每日前沿恢复正常更新；历史的待读、已读、太泛和隐藏记录可重新开始。
- 特刊工作台左侧明确显示推荐、收藏或待核验状态及期刊名。
- 特刊完整征稿范围会清除网页脚本与样式，并以中文翻译、英文原文的顺序显示。
- 内置 Helsinki-NLP OPUS-MT 英中模型，使用 CTranslate2 在本机离线翻译；手工译文不会被覆盖。
- 选刊会把 `&` 与 `and` 等期刊名变体视作同一本期刊，正确排除本论文的拒稿期刊。
- 每条选刊结果都有“排除”按钮；排除只作用于当前论文，工作台不会关闭。
- Elsevier、Springer Nature、Taylor & Francis、Wiley 会结合出版社名称、子品牌与官网域名识别。
- 特刊发现会先用 OpenAlex 根据研究关键词定位真实期刊，再读取出版社专题页；Taylor & Francis 使用其官方征稿接口，Elsevier 官网受限时使用只读发现通道并明确标为“未官网核验”。
- 其他已确认出版社的特刊匹配分按 50% 计入；出版社未知的征稿仍保留在待核验区。

## 数据说明

个人数据继续保存在 `%LOCALAPPDATA%\科研助手\UserData`（或你在设置中指定的位置）。安装升级不会删除论文、期刊、任务、成果、研究画像与密钥设置。

v12.1 正式支持从 v10.0 及以后版本升级；不再承诺兼容 v10.0 之前的数据格式。

每日前沿本次只清理状态为“待读、已读、太泛、隐藏”的旧推荐；已标记相关和尚未处理的记录保留。正式清理前会生成完整备份。
