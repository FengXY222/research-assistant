# 科研助手 v12.2.0 使用说明

本版继续只保留小组件模式。HOME、WORK、PAPERS、LIBRARY 是四个工作台；研究设置、为论文选刊和特刊征稿在需要集中处理时打开独立大界面。数据保存在 `%LOCALAPPDATA%\科研助手\UserData` 或设置中指定的位置，支持 v10.0 及以后数据。

HOME 的“今日下一步”集中显示最需要推进的具体任务，并可直接跳转到对应论文与期刊记录；WORK 继续承载完整待办与四象限安排。

## 每日前沿

1. 系统先按核心主题、已有论文、收藏样本和探索方向检索真实论文并去重。
2. AI 阅读标题、摘要和研究画像，给出 AI 内容相关性分数与“为什么推荐”。检索命中、孤立缩写或共用机器学习方法不能直接放行。
3. 内容分达到最低线后，再应用期刊分区门槛与期刊偏好分；信息不足的论文进入待复核，不冒充正式推荐。
4. 配置 EasyScholar 时，主信息流只接收已确认的 JCR Q1/Q2 期刊论文；未知分区暂存，预印本进入独立区域。未配置时不执行分区硬门槛。
5. 今日推荐、待内容复核和历史记录按批加载。到达底部可继续加载，切换视图不会一次生成全部卡片。

### 期刊偏好分

在“研究设置 → 发现策略”打开“管理期刊偏好分”。工作台支持按期刊名、出版社或 ISSN 搜索，并可筛选全部、已评分和未评分期刊。

| 期刊分 | 建议用途 |
|---|---|
| 100 | 必看期刊，显著提高排序。 |
| 80 | 重点关注。 |
| 60 | 扩展阅读。 |
| 50 | 默认中性分。 |
| 0 | 明确降到队尾，但不替代内容和分区门槛。 |

综合排序默认由 **75% 内容相关性 + 25% 期刊偏好** 组成。期刊权重可在 0%–50% 间调整；没有单独评分的期刊使用界面中显示的默认分。卡片同时显示综合分、内容分和期刊分，便于看清排序原因。

### 已确认的研究边界

探索方向采用低权重探索：它必须先通过同一内容最低线，只在综合排序时降权，不能用弱相关内容填满推荐。

| 方向 | 处理方式 |
|---|---|
| 土壤碳矿物保护、矿物结合态碳、碳铁结合 | 保留，不被宽泛的 mineral 排除词误伤。 |
| 纯矿物学、无土壤碳联系的材料或化学研究 | 排除。 |
| 土壤肥力、土壤健康及质量指数评价 | 作为独立方向推送，不要求同时出现 SOC。 |
| 服务滑坡评价的 DEM、地形和水文方法 | 低权重探索；仍须先达到内容最低线。 |
| 仅共享机器学习、SHAP 等方法的其他学科 | 不因方法相同而推送。 |

将论文标为已读后会立即从今日推荐移入已读视图；相关、待读、太泛、隐藏等操作保持当前列表位置。收藏、忽略、已有论文及一句话评价继续参与长期/短期画像学习。

## 研究设置与扫描版 PDF

关键词工作台分为生效关键词、待确认和排除关键词。英文词右侧显示可编辑中文翻译，生效词按权重降序排列。锁定词不由 AI 修改；手动删除的普通词进入隐藏阻止名单，不会在每日整理时反复出现。

导入扫描版 PDF 时，本机先逐页 OCR，再由 AI 整理识别文本并提取、翻译、合并关键词。每天首次启动可在后台整理画像，也可手动整理；整理前只保留最近一次当天快照，失败时不改写原画像，并可一键撤销。

## 为论文选刊

从 PAPERS 的快捷入口选择论文后进入 1024×768 工作台。系统优先通过 OpenAlex、Semantic Scholar 和 Crossref 查找相似真实论文，并汇总其真实发表期刊；AI 可以补充库外候选，但只有在期刊身份、ISSN、出版社和官方主页可核验时才展示。

已拒稿、为该论文手动排除、停止出版、身份无法核验及本轮重复候选会淘汰。配置 EasyScholar 时，所选 JCR/中科院分区是硬条件；出版社是硬偏好，已知且不匹配时淘汰，未知出版社保留待核验。费用和预计速度用于排序，主题契合度必须达到最低线。加入期刊库、排除或加入投稿路径后，工作台保持打开。

## 特刊征稿

LIBRARY 默认仍打开每日前沿，“特刊征稿”与每日前沿、期刊库并列。小组件显示未读数、收藏数、最近截止日期、已收藏和最高匹配特刊；点击“打开特刊工作台”进入独立 1024×768 界面。

工作台收录期刊 Special Issue、Topical Collection、Research Topic、Article Collection 等专题征稿，排除会议、Workshop、图书章节、普通常年征稿和仅邀请投稿。聚合来源可用于发现；有截止日期且信息足够新时允许进入列表，并醒目标记“未官网核验”，以后继续尝试官网核验。

系统使用综合研究画像和每篇论文的特刊画像读取完整征稿范围并计算匹配分。同一特刊只显示一张卡片，同时列出适合关联的论文。筛选出版社、费用、JCR、中科院分区或截止期限时，未知信息不会被误删，而是排在确定匹配项之后。

### 状态与操作

| 操作 | 结果 |
|---|---|
| 收藏、忽略、标为已读 | 立即更新个人状态；后台刷新不能覆盖。收藏和忽略均可撤销。 |
| 加入期刊库 | 保存期刊及已有核验证据，工作台保持打开。 |
| 关联论文 | 只建立特刊与论文的关联。 |
| 加入投稿路径 | 缺失期刊先快速入库，再创建包含特刊名和截止日期的投稿候选。 |
| 创建准备任务 | 单独创建并自动关联论文、特刊和截止日期。 |
| 核验依据 | 展开完整征稿范围、相似论文、ISSN、官方证据、EasyScholar 结果和更新时间。 |

关闭、已过期或截止日期冲突的征稿不能创建新投稿路径和准备任务，但仍可查看、入库和关联。手动刷新显示进度并可取消；取消只停止派发新任务，保留已安全完成的结果。程序启动后会判断是否距上次有效检查超过 24 小时，持续运行时每小时重新判断。来源失败按 15 分钟、1 小时、6 小时逐级退避，不把失败误记为成功。

收藏特刊后，在截止前 90、60、30、14、7、3 天提醒。若错过多个节点，只补发最近一个仍有意义的提醒；截止日期变化或征稿关闭会单独提醒。

## 数据与升级

- 安装器不会把程序文件与个人数据混在一起，覆盖安装和卸载不会删除用户数据。
- 程序启动时会恢复未完成的跨文件事务，避免投稿路径、任务和特刊关联只写入一半。
- v12.2.0 支持 v10.0 及以后数据；不再承诺兼容 v10.0 之前的旧格式。
- 安装前仍建议保留一份用户数据目录备份。正式安装流程会进行安装前后 SHA-256 核对。
