# 科研助手 v12.0 使用说明

科研助手 v12.0 是一个本地优先的个人科研工作小组件。它把每天要做的事、论文投稿路径、期刊经验、研究画像、前沿论文和特刊征稿放在同一个工作流中；核心记录保存在本机 `data` 文件夹，不需要账号、服务器或数据库。

## v12.0 核心变化

- **只保留小组件模式**：不再提供另一套软件模式，四个工作台都围绕日常常驻的小窗口设计。选刊、研究设置和特刊工作台仍可按需打开独立 1024×768 窗口。
- **共享科研智能核心**：关键词、已有论文、收藏、忽略、已读、关联和一句话评价共同形成长期/短期画像，每日前沿、选刊和特刊使用同一套可信信号。
- **本地 OCR 与关键词治理**：扫描版 PDF 可在本机逐页 OCR，AI 再根据识别正文提取、翻译、合并和调整关键词；低置信度新词进入待确认区。
- **真实证据驱动推荐**：每日前沿先检索真实论文，选刊先看相似论文真实发表期刊，特刊先从官网与聚合来源发现真实征稿；AI 负责理解和评分，不负责虚构事实。
- **可核验、可回退**：分区、ISSN、出版社、官网、相似论文和数据更新时间均在“核验依据”中展示；画像每日整理失败时不改原数据，当天可一键撤销最近一次整理。

## 1. 安装与数据安全

1. 覆盖安装会沿用原安装目录，并跳过已有 `data`；卸载也不会删除数据目录。
2. AI、EasyScholar 和公开论文接口都是增强项。外部服务不可用时，任务、投稿、期刊库及已保存数据仍可正常使用。
3. 若在设置中迁移过数据，请以“设置 → 数据与备份”显示的当前路径为准。
4. 升级前建议先点一次“立即备份”。科研助手也会在关键迁移和每日画像整理前保留可恢复副本。

## 2. 四个工作台

| 工作台 | 内容 | 常用动作 |
| --- | --- | --- |
| HOME | 今日任务、论文状态、今日下一步、投稿观察、简报、灵感与待读 | 处理当天行动并直达对应记录。 |
| WORK | 今日待办、任务历史、灵感、值得阅读 | 排任务四象限，记录想法和待读。 |
| PAPERS | 论文投稿记录、拒稿归档、成果、选刊快捷入口 | 维护一篇论文的多条投稿经历。 |
| LIBRARY | 每日前沿、期刊库、特刊征稿 | 发现论文、维护期刊事实、跟踪专题征稿。 |

顶部导航只切换工作台，不复制数据。LIBRARY 每次进入仍默认显示“每日前沿”；“期刊库”和“特刊征稿”是同级页签。

## 3. HOME：先看今天要推进什么

- **今日任务**直接展示具体任务和完成进度；任务较多时区域滚动，不会把右侧论文状态压扁。
- **今日下一步**只突出最值得推进的论文动作。点击后进入 PAPERS、展开对应论文，并让目标期刊短暂高亮。
- **投稿推进与投稿观察**分开呈现：需要决策的动作优先，等待中的状态保持紧凑完整边框。
- **灵感与待读**只显示必要预览，点击“查看与编辑”进入 WORK。
- 顶部 `＋` 是统一收件箱；保存前会先让你确认它属于待办、灵感、待读还是期刊候选。

## 4. WORK：任务、灵感与待读

### 4.1 今日待办

- 任务支持开始/结束日期、每日循环、无日期任务和完成历史。
- 点击“优先级”可直接选择重要且紧急、重要不紧急、紧急不重要、不重要不紧急；长按任务时也会出现清晰的四象限面板。
- 右侧 `⥮` 是排序手柄。拖动只改变顺序，不会把符号替换成文字。
- 无日期未完成任务会持续保留；跨天任务按设置迁移，完成项进入历史。

### 4.2 灵感与待读

灵感适合记录尚未成熟的方法、问题和实验想法；待读适合保存值得进一步阅读的论文及加入原因。二者都支持编辑、删除和排序，每日前沿的论文也可直接加入。

## 5. PAPERS：论文与投稿路径

一篇论文是外层记录，每一次准备投稿、投稿中、修改中、拒稿、接收或发表都是独立的期刊经历。因此拒稿只归档当前期刊，不会删除论文和其他投稿路径。

- 期刊经历可记录出版社、投稿日期、状态、回复截止日、结果、备注和时间线。
- “修改中”应填写回复截止日，HOME 会优先提示临近或逾期动作。
- 论文题目、关键词、摘要和关联 PDF 会参与研究画像、相似论文检索、选刊及逐篇特刊画像。
- “为论文选刊”快捷入口会打开独立选刊工作台，并自动选中当前论文。

## 6. 研究画像与关键词工作台

### 6.1 三个区域

| 区域 | 作用 | 可用操作 |
| --- | --- | --- |
| 生效关键词 | 参与检索和推荐，按权重从高到低排列 | 编辑中文翻译、调权、锁定、移除。 |
| 待确认关键词 | 保存 AI 新发现但证据不足的方向 | 接受、编辑或拒绝。 |
| 排除关键词 | 阻止不相关主题进入推荐 | 逐个编辑英文/中文、删除或锁定。 |

每行显示英文词、中文翻译、权重、来源和锁定状态。手动锁定词属于长期强信号，AI 不能修改、合并、调权或删除。手动删除的普通关键词会进入永久隐藏阻止名单，不会在以后整理时反复出现。

### 6.2 PDF 与本地 OCR

导入 PDF 后，系统先尝试直接读取正文；若页面没有可用文字，会在本机逐页进行 OCR。扫描版 PDF 因而不必先转换为可编辑文件。OCR 只负责识别，随后仍由 AI 整理正文并提取、翻译、合并关键词；低置信度结果只进入“待确认关键词”。

图片清晰度、旋转角度和复杂表格会影响识别质量。处理期间会显示阶段和进度；失败时不改动当前画像。

### 6.3 每日整理与一句话评价

- 每天首次启动在后台整理一次，也可手动触发。
- AI 可新增、翻译、合并、调权和删除普通关键词，也可新增或删除排除词，但不能触碰锁定词和永久隐藏名单。
- 修改前只保留当天最近一次快照；结果页显示新增、合并、调权、删除和排除词变化，可一键撤销当天整理。
- 一句话评价实时进入画像。例如“不是我的研究方向”会被识别为强负信号，“多推类似内容”会被识别为强正信号；其余行为在每日整理时汇总。

## 7. 每日前沿

### 7.1 发现与画像学习

系统通过 OpenAlex、Semantic Scholar 和 Crossref 发现并去重真实论文。已有论文和锁定关键词是不衰减的长期强信号；收藏和关联项目是强正样本，详情打开和已读是弱正样本，明确忽略是强负样本。没有操作不代表不喜欢，行为信号会随时间减弱。

每日前沿先按标题、摘要和完整画像进行内容审查。核心匹配存在时，主信息流至少 50% 为核心匹配；完全没有核心结果时，才使用合格的画像探索补足。每篇卡片明确写出“为什么推荐”。

### 7.2 分区与预印本

- 配置 EasyScholar 时，主信息流中的期刊论文必须经 EasyScholar 或本地期刊库确认属于 JCR 1/2 区；未知分区进入待核验，不直接推送。
- 未配置 EasyScholar 时不执行分区淘汰，检索到的合格论文均可展示。
- 预印本进入独立“前沿预印本”区域，不显示成期刊论文，也不套用期刊分区。
- 每日列表同时显示 JCR 分区和中科院分区；核验失败时保留旧值并标记更新时间。

卡片显示 0-100 的 AI 内容相关性分数。研究对象与任务联系决定是否合格，低权重探索单独降低排序权重；期刊分区负责质量门槛，不能靠高分抵消内容不相关。AI 不能覆盖已核验的期刊事实。

## 8. 为论文选刊

选刊工作台不再要求 AI 凭记忆直接报期刊名，流程如下：

1. 根据题目、关键词和摘要，从 OpenAlex、Semantic Scholar、Crossref 找相似真实论文。
2. 汇总这些论文的真实发表期刊，形成第一批候选。
3. AI 可补充库外期刊，但必须核验真实存在、ISSN、出版社和官方主页；身份无法核验的期刊不进入结果。
4. 已拒稿、停止出版、身份不明和本轮重复候选淘汰。
5. 配置 EasyScholar 时，所选 JCR/中科院分区是硬条件；所选出版社始终是硬条件。未知出版社可保留待核验，已知且不匹配时淘汰。
6. 费用和预计速度用于排序；主题契合度必须达到选择的最低线。
7. 多轮搜索直到没有新合格结果或达到安全上限，展示所有轮次的合格期刊，不再人为限制为 5 本。

结果卡默认只显示 AI 总分、推荐理由、出版社、JCR/中科院、费用和预计速度。展开“核验依据”可查看相似论文、官方 Aims & Scope、ISSN、身份来源、EasyScholar 结果和更新时间。

“加入期刊库”或“加入投稿路径”始终作用于你点击的那一本期刊，完成后选刊窗口不会关闭。

## 9. 特刊征稿

### 9.1 小组件与独立工作台

LIBRARY 的“特刊征稿”小组件显示收藏项、高匹配新征稿、最近截止日期和未读数量。点击卡片或“打开工作台”进入独立 1024×768 窗口；推荐、收藏、待核验、状态变化分开显示。

同一特刊若匹配多篇论文，只显示一张卡片，并列出全部可关联论文。可切换“综合研究画像”或具体论文画像查看结果。

### 9.2 收录与核验

- 收录 Special Issue、Topical Collection、Research Topic、Article Collection 等期刊专题征稿。
- 排除会议、Workshop、图书章节、普通期刊常年征稿和仅邀请投稿。
- 聚合来源信息足够新且有截止日期时可进入结果，但会醒目标记“待官网核验”，以后每天继续尝试。
- AI 阅读完整征稿范围后计算匹配分并写明理由；出版社、JCR、中科院、费用、截止日和官网状态作为独立事实展示。
- 筛选开启后，未知信息仍保留在结果末尾，避免因资料暂缺把潜在合适征稿全部删除。

### 9.3 操作与提醒

- **收藏 / 忽略**：进入研究画像的强正/负信号。
- **关联论文**：只建立特刊与论文的关联，不修改投稿路径。
- **加入投稿路径**：缺失期刊会先快速入库，再创建含特刊名称和截止日期的投稿候选。
- **创建准备任务**：单独生成任务，并关联论文、特刊和截止日期。
- 收藏后在截止前 90、60、30、14、7、3 天提醒；截止变化或征稿关闭时另行提醒。

每次启动若距离上次检查超过 24 小时，会在后台刷新；也可手动刷新。全部操作都有进度反馈，完成后工作台保持打开。

## 10. 期刊库与 EasyScholar

期刊名可直接选中复制。列表使用“中科院 1区”等紧凑文字，并用状态色区分已核验、待补和冲突；出版社可通过 Crossref 做模糊校验，缺失或无法核验的信息只标记，不删除期刊。

在设置中填写 EasyScholar 密钥后，期刊库、每日前沿、选刊和特刊会更新可用的 JCR、中科院分区等事实。密钥仅保存在本机；外部服务失败时保留现有数据。开放平台地址为 [EasyScholar](https://www.easyscholar.cc/console/user/open)。

## 11. 设置、主题与快捷操作

- 12 套主题支持即时预览，保存与取消不会重复重建主窗口；设置、菜单、弹窗、独立工作台使用同一主题。
- 支持舒适/紧凑信息密度、置顶、固定、透明度、鼠标穿透和托盘显示/隐藏。
- 默认全局双击空格显示/隐藏；中文输入法开启时自动禁用，也可改成组合键或关闭。
- 数据页支持立即备份、恢复备份、迁移数据路径和导入旧版 `data`。
- AI 设置用于研究画像、相关性理解、选刊和特刊匹配；所有 AI 操作都显示进度，失败不会清空原记录。

## 12. 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 双击程序没有新窗口 | 软件可能已在运行；使用全局显示快捷键或托盘图标唤醒现有实例。 |
| 关键词删除后又出现 | 检查是否删除的是锁定词；普通词经手动删除会进入隐藏阻止名单，保存后不应再生成。 |
| OCR 没提取到关键词 | 检查 PDF 是否存在、页面是否清晰；等待 OCR 和 AI 两阶段完成，并查看进度提示。 |
| 每日前沿没有期刊论文 | 配置 EasyScholar 后只推送已确认 JCR Q1/Q2；可到待核验流查看未知分区结果。 |
| 选刊结果少 | 检查出版社、分区硬条件和主题最低线；费用与速度不会单独淘汰期刊。 |
| 特刊显示“待官网核验” | 聚合信息仍可参考，系统会在以后每日刷新中继续尝试官网核验。 |
| AI 或联网失败 | 本地功能和旧结果不受影响；检查网络、密钥、模型地址后手动重试。 |

## 13. 建议的日常节奏

1. 打开 HOME，先处理今日任务和“今日下一步”。
2. 在 WORK 安排真正重要的任务，把新想法放入灵感。
3. 在 PAPERS 更新投稿状态、回复期限和论文摘要。
4. 查看 LIBRARY 的每日前沿，对重要论文收藏、已读、忽略或写一句话评价。
5. 检查特刊小组件的高匹配新项和最近截止日，需要时关联论文或建立准备任务。
6. 每月检查一次研究画像、期刊库和数据备份，让锁定词保持少而准确。
