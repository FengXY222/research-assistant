# 科研助手 v13.0.0 使用说明

## 1. 版本定位

v13.0.0 保留原有四个工作台与小组件使用方式，重点重构每日前沿、特刊征稿和为论文选刊。三块功能统一采用“广泛召回 → 事实初筛 → 本地规则双轴评分 → 可选 AI 有限调整 → 动态分层展示”。AI 没有配置、额度不足或临时失败时，本地评分仍会独立完成推荐。

## 2. 升级与首次启动

1. 首次启动 v13 时会先为旧数据创建可校验备份，再执行结构迁移。
2. 迁移失败时不会覆盖旧数据，可在设置中查看备份并恢复。
3. 如果启用开机自启，程序会创建延迟 30 秒的当前用户启动任务，并立即做一次真实启动探针；任务计划程序不可用时才回退到当前用户启动项。
4. 开机启动后程序进入托盘，不主动弹出主窗口。

## 3. 每日前沿

### 3.1 数据源和发现方式

每日前沿独立检查 OpenAlex、Crossref、Semantic Scholar、Europe PMC、DOAJ 和 arXiv。系统同时执行六类召回：关键词、语义相似、引用网络、确认作者团队、全部关注期刊和主题扩展。每个来源单独记录成功、失败和水位，某一来源失败不会让其余来源作废。

数据源开关可在每日前沿设置中调整；需要 Key 的来源统一到“总设置 → 智能增强与数据源”配置，密钥使用当前 Windows 用户加密保护。

### 3.2 评分和展示

每篇候选分别计算“内容相关度”和“科研价值”。每轴本地规则最多 66 分，AI 只能在每轴最多调整 34 分；没有 AI 时会把本地规则分规范化为完整分数，不会写入 0 分占位。

页面只显示通过标题、基本身份、内容证据和双轴有效分硬门槛的记录，并按 A、B、C 金字塔层级排序。推荐数量不设上限或下限；当天总体价值不足时，系统会在不突破硬门槛的前提下使用 14、30、90 天窗口逐级回补。

“保留未读”开启时，昨天及更早的未读论文继续留在同一个每日前沿页面；关闭后会删除展示内容，但保留去重指纹，避免今后重复推送。同一成果的预印本、在线版和正式版会合并为一个工作家族。

## 4. 特刊征稿

特刊同时检查六个官网来源及已接入的合格第三方聚合来源。第三方结果会保留原始链接、抓取时间和证据；官网暂时无法核验但主题明确相关时，会标注“官网暂未核验”后供用户确认，不进入隐藏 Pending 页面。

特刊必须具有可用标题、期刊或出版社身份、主题范围或关键词、可访问来源链接、截止日期或 rolling 状态，以及有效双轴分数。缺失这些基本信息、0 分记录、已截止记录和事实冲突记录不会推送。

系统优先保证合格的 Elsevier、Springer Nature、Wiley 和 Taylor & Francis 特刊可见，但不会为了出版社均衡或凑数量推送垃圾内容。MDPI、Frontiers 与第三方结果仍按相同的内容门槛和出版社质量规则参与评分。

## 5. 为论文选刊

候选同时来自相似论文的真实发表期刊和完整本地期刊库。结果分别计算“论文—期刊契合度”和“投稿策略可行性”，再动态形成冲刺、主投、稳妥和探索层级，不固定推荐数量。

只有确认停刊、确认不接受文章类型、事实性重复或用户永久排除的期刊会从当前候选中移除。分区未知、周期未知、费用未知、身份暂未核实和低相关候选保留为待核实，不用 0 分伪装成确定结论。

用户可主动设置 JCR Q1/Q2 等严格条件；这是本次选刊约束，不会成为系统默认硬过滤，也不会永久删除底层证据。AI 可以调整两轴各最多 34 分，但不能推翻事实硬门槛。

## 6. AI 使用本地资料

在“总设置 → 智能增强与数据源”中可决定是否允许 AI 按任务读取本地笔记、论文 PDF、投稿记录和审稿意见。系统默认执行项目隔离和任务最小化，只抽取当前任务所需片段，并过滤邮箱、电话、身份证号和账号等无关个人信息。

论文编辑窗口可对整篇论文关闭 AI 访问，也可对单个关联文件关闭“AI 可读”。启用资料使用清单后，可在设置中查看最近的调用记录；清单只保存资料类别、记录标识、摘要哈希和字符数，不保存原文或密钥。

## 7. 定时任务、失败恢复与备份

- 当天任务错过后会补跑；已经成功的任务不会重复执行。
- 部分来源失败时只补失败来源，不重新抓取已成功来源。
- 召回、补全、去重、评分和提交均有阶段检查点；崩溃后从最近完整阶段幂等续跑。
- 自动备份包含每日增量和每周完整备份；备份不包含可还原的明文 API Key。

## 8. 使用建议

先在研究画像中维护核心主题、方法词、确认作者和关注期刊，再到总设置检查六个核心来源是否启用。每日前沿与特刊第一次完整刷新可能比旧版更慢，因为 v13 会逐来源验收并补全证据；后续刷新会利用水位和缓存减少重复请求。

对推荐使用“相关、太泛、已读、收藏”等反馈即可。手工锁定内容不会被行为学习覆盖，行为学习只做有限调整并可撤销。
