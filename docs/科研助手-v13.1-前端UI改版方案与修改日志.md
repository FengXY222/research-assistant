# 科研助手 v13.1 前端 UI 改版方案与修改日志

> 本文档是 v13.1 前端改版的**唯一计划与留痕文档**。每完成一步，在「修改日志」追加记录（改了哪些文件、删了什么、为什么），方便后续回溯和二次修改。

## 一、已确认的产品决策（2026-09-18 与作者确认）

| 决策点 | 结论 |
|---|---|
| 主导航 | **保持现状**：侧边栏 4 工作台（HOME/WORK/PAPERS/LIBRARY）+ 组内 chip 行，两层结构不动 |
| 大型工作台弹窗 | **保持现状**：特刊工作台、为论文选刊、研究设置的弹窗形态不动（只统一视觉） |
| 设置类界面 | **合并为设置中心**：外观 / 通用与数据 / AI 服务 / 研究画像 / 期刊工具 五分区，一个入口 |
| 主题 | **只保留一个主题**（fog_teal 基底），删除多主题选择 |
| 视觉风格 | **彩色强调卡片风**：功能区 accent 色、左侧色条卡片、彩色状态徽章、accent 主按钮 |
| 核心诉求 | ① 去厚去冗余 ② 主次分明（主要功能突出、次要退后）③ 好看不单调 |

**边界（不许动）**：utils/ 后端逻辑、数据格式、窗口形态（520x680 无边框）、页面 vs 弹窗划分。
