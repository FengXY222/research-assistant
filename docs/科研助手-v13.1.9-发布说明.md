# 科研助手 v13.1.9

本版本整合前期 SQLite、导航和独立 PDF 翻译改动，并落实全项目审查的六个实施批次及17项对应修复。

- 防止前沿旧快照覆盖新数据，结果及任务状态原子提交；保存失败明确提示并可重试。
- 完整备份校验和故障重试，数据库锁与损坏分类处理，按数据集安全迁移。
- 区分空闲和手动任务，保留暂停检查点；页面隐藏和退出不在界面线程等待。
- 成果、前沿、投稿记录、灵感、待读可见区域卡片；期刊库真实 SQLite 分页。
- 词典优先及模型闲置释放，批量缓存写入，候选池与可清理网络缓存分离。
- 补齐 PDF 翻译组件备份、密钥排除及数据目录重定位；适配自定义 AI 接口能力。
- 锁定构建依赖，保守精简独立翻译运行时。

完整测试：702项通过（79.43秒）。正式数据隔离副本连续切换80次，控件数量不变，内存增加约0.11 MB。详细边界见 [17项验收结果](全项目17项修复验收结果-20261002.md)。

## 下载与升级

下载 Release 中的 `research-assistant-v13.1.9-setup.exe`，退出旧版后安装。本地安装包名为 `科研助手-v13.1.9-安装包.exe`；两者内容及SHA256相同。旧个人数据保留，安装包不包含开发机个人数据或密钥。SHA256 校验值另附。

## 已知边界

软件未做代码签名，Windows 可能提示未知发布者。没有逐一重测所有在线来源或执行新的收费 AI 全文翻译；此前空前沿的根因需下一次联网诊断确认。单次网络请求取消可能等待超时，手动翻译仍独立于主程序空闲任务规则。
