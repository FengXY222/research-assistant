# 科研助手 v12.1.3 使用说明

本版重新接入每日前沿的内容审查，不清空论文、期刊、画像、已读、待读、收藏或隐藏记录。仅保留原有小组件模式。

## 每日前沿的顺序

1. 根据核心主题、已有论文与收藏样本、探索方向分路检索真实论文，合并重复记录。
2. AI 阅读论文标题、摘要与完整研究画像，判断具体研究对象、任务和方法联系。检索命中、旧分数、SOC 等孤立缩写或通用机器学习方法不作为放行依据。
3. 内容相关性达到 75 分且证据支持的论文进入下一阶段；信息不足、AI 失败或尚未审查的论文暂存，不冒充合格推荐。
4. 配置 EasyScholar 时，期刊流只接收已由 EasyScholar 或期刊库确认的 JCR Q1/Q2 论文。未知分区暂存，预印本独立展示；未配置时只跳过分区门槛，不跳过内容审查。
5. 有核心匹配结果时，推荐中至少一半为核心匹配，不用大量弱探索填满数量。完全没有核心结果时，允许内容合格的画像探索补足。

## 已确认的研究边界

| 方向 | 处理方式 |
|---|---|
| 土壤碳矿物保护、矿物结合态碳、碳铁结合 | 保留；不能被旧的宽泛 mineral 排除词误伤。 |
| 纯矿物学、无土壤碳联系的材料/化学研究 | 不推送。 |
| 土壤肥力、土壤健康及质量指数评价 | 作为独立方向保留，不要求必须同时出现 SOC。 |
| 对滑坡评价有具体帮助的 DEM、地形、水文方法 | 低权重探索；先达到内容最低线，排序时乘以 0.65。 |
| 仅共享机器学习、SHAP 等方法的其他学科论文 | 不因方法相同就推送。 |

卡片显示 AI 内容相关性分数。低权重探索仍显示真实相关性分数，但排序单独降权。例如相关性 80 分、排序权重 0.65 时，按 52 分参与排序，不把最低相关性要求降为 52 分。

## 复核与历史记录

- “检查更新”自动进行内容审查。“AI 复核”使用同一套内容规则。
- 每次最多新增审查 80 篇，已验证缓存可直接复用；其余进入“待内容复核”，后续复核继续处理。
- “待内容复核”“分区待核验”“已排除候选”可分别查看。已核验的 Q3/Q4 也不会进入今日推荐。
- 已读、待读、相关、太泛、隐藏记录继续保留；后台更新不会覆盖刚完成的个人操作。
- 旧缓存里尚未内容审查的未处理记录不再直接推送。AI 不可用时，新候选暂存；之前通过内容审查的缓存可以保留。
- 本版没有重写关键词，也没有重新恢复已隐藏的论文。

## 数据与适用范围

数据仍保存在 `%LOCALAPPDATA%\科研助手\UserData` 或设置中指定的位置，支持 v10.0 及以后的数据。

本轮使用固定的 40 篇诊断样本检验规则，并以隔离数据运行自动测试。样本不是随机抽样，不能据此宣称实际推荐准确率。在线摘要补齐、更多文献源和真实检索召回率优化不属于本次更新。
