# 科研助手 v11.5.1 使用说明

科研助手 v11.5 是一个本地优先的个人科研工作台：每天打开后先知道下一步该做什么，再把投稿经历、期刊经验、成果 PDF 和前沿阅读慢慢沉淀下来。它不需要账号、服务器或数据库；核心记录保存在本机 `data` 文件夹。

## v11.5.1 本轮修订

- **HOME 重做为今日工作台**：任务、论文状态、投稿观察和科研简报按工作优先级重新分区；小组件宽度下自然纵向展开并可滚动，任务增多不再挤压论文状态或投稿观察。
- **选刊结果更聚焦**：摘要与条件位于可滚动的上半区，AI 推荐结果默认占主要可视区域；JCR/中科院分区可持续多选，结果行只展示 AI 总分、推荐理由和下一步操作。
- **研究设置更适合小组件**：关键词补充、论文记录提取和状态提示改为清晰的纵向工作流；可从已记录论文提取保守的候选关键词并放入待确认区。
- **跨页面细节收口**：投稿观察在无待推进动作时自动占满一行；小组件中统一采用可靠的中文操作文案，避免特殊符号显示异常。

## v11.5 更新内容

- **主题更流畅、选择更多**：切换或保存设置不再卡顿；新增朝霞青、极光夜、鸢尾橙阳等非单色主题，共 12 套。
- **HOME 更聚焦**：今日任务直接展示具体待办；今日下一步聚焦论文动作（点击可直达对应论文并闪烁其期刊）；最近节点不再与上面两块重复。
- **WORK 四象限**：今日待办新增直接的“优先级”按钮，长按时显示居中的四象限面板，也可直接点选；拖动仍可使用。
- **选刊升级为 AI 决策工作台**：按论文摘要推荐至少 5 本期刊；提交前可筛选出版社、付费方式、JCR 分区和中科院分区，并选择 OA 偏好与发表时效。推荐结果只保留 AI 总分和理由，可直接加入投稿路径或快速入库。
- **LIBRARY 默认每日前沿**：打开 LIBRARY 首先看到每日前沿，期刊库作为子页；期刊库在小组件宽度下会自动换行而不横向溢出。
- **每日前沿与研究画像**：锁定词会持续锁定；可手工补充关键词，也可从一篇论文中提炼关键词。设置成为独立工作台，便于维护研究方向、排除词和分区筛选。
- **EasyScholar 期刊数据**：在设置中填入密钥后，期刊库、选刊和每日前沿会更新 JCR 分区、中科院分区等信息；密钥可用时，每日前沿默认不再推荐三四区文章。

## 1. 先确认三件事

1. 安装升级不会替换已有 `data`。安装器会沿用已安装的位置，并跳过 `data\*`；卸载也不会删除它。
2. AI 和联网检索都是可选项。没有配置 DeepSeek 或网络不可用时，待办、投稿、期刊库、本地选刊和历史记录仍可使用。
3. 请从同一份安装目录启动软件。若在设置中迁移过数据路径，以设置页面显示的“本地数据”路径为准。

## 2. 两种界面模式

在“设置 → 外观与工作方式”中切换，二者使用同一份数据、但分别记住窗口尺寸和位置。

| 模式 | 适合什么情况 | 行为 |
| --- | --- | --- |
| 桌面小组件 | 日常常驻、像便签一样快速记录 | 无边框、小窗口、可置顶/固定/透明；最小化收进系统托盘。 |
| 软件模式 | 集中整理论文、期刊和成果 | 正常应用窗口，四个工作台内容连续展开；最小化保留任务栏入口。 |

小组件模式下，点击“固定”会锁住当前位置和大小；下次打开会回到该位置。鼠标穿透开启后，双击顶部“科研助手”文字可解除穿透。

## 3. 四个工作台

旧版的七个入口已收束为四个工作台，所有原有数据和操作入口仍可到达。

| 工作台 | 包含内容 | 常用入口 |
| --- | --- | --- |
| HOME | 今日概览、今日下一步、最近节点、每日简报、灵感和待读预览 | 双击卡片可直达对应记录。 |
| WORK | 今日待办、灵感便签、值得阅读 | 顶部子标签在“任务 / 灵感与待读”之间切换。 |
| PAPERS | 投稿记录、拒稿归档、成果 | 一篇论文可保留多个期刊经历。 |
| LIBRARY | 期刊库、每日前沿 | 期刊信息维护、为论文选刊、前沿阅读与反馈。 |

软件模式中，四个工作台会以连续页面形式展开，顶部锚点用于快速定位，不会复制或拆分数据。

## 4. HOME：每天先看这里

HOME 只放当前行动需要的信息。

- **今日任务 / 论文状态**：任务是首要工作面，直接展示具体待办与完成进度；论文状态保留投稿中、修改中、已发表统计。
- **投稿推进 / 投稿观察**：需要决策的投稿动作与等待观察的期刊状态分开呈现；没有推进动作时，观察面会自动占满整行。
- **今日科研简报**：说明当天前沿检索的推荐数量、最高总分和优先期刊命中。
- **灵感与待读预览**：窄窗口纵向排列、宽窗口并列显示；点击“查看与编辑”进入 WORK。
- **小组件布局**：HOME 是可滚动工作台，任务较多时向下展开，不会压缩已在首屏的工作信息。

顶部 `＋` 是统一快速收件箱。输入一句话后先在确认页检查分类，再保存为待办、灵感、待读或期刊候选，不会直接写入数据。

## 5. WORK：任务、灵感与待读

### 5.1 今日待办

- 可快速输入任务，也可打开编辑页设置开始/结束日期、每天循环、四象限、是否无日期任务。
- 无日期任务会持续显示到完成，不会凭空生成截止时间。
- 未完成任务跨天时会提示是否迁移；已完成任务进入历史任务，一个月前的完成项会定期清理。
- 任务前的颜色和“紧急重要”标签来自四象限；长按/拖动可调整象限，右侧拖动手柄用于排序。

### 5.2 灵感与值得阅读

- 灵感适合记录还未成为任务的研究问题、方法或待查方向；可编辑、删除、排序。
- 值得阅读仅有“未阅读 / 已阅读”状态，可记录加入原因。
- 每日前沿中的论文可一键加入待读或标记为灵感，HOME 会自动显示紧凑预览。

## 6. PAPERS：一篇论文，多个期刊经历

论文是外层记录，期刊经历是内层记录。因此同一篇论文可同时保存准备投稿、正在外审、已拒稿或曾经投过的多个期刊。

### 6.1 期刊经历

每条期刊经历独立保存：期刊名、出版社、投稿日期、状态、结果、备注、回复截止日和时间线。

- 编辑并保存状态时，投稿日期会默认更新为当天；若补录历史记录，可手动填写历史日期。
- 投稿日期、状态更新时间和时间线日期不能晚于今天；旧数据若存在异常未来日期，会在投稿记录中标记并可一键修正。
- 状态为“修改中”时应填写回复截止日。HOME 会优先显示临近和逾期回复。
- 状态为“拒稿”时，只归档该条期刊经历；论文本身和其他期刊经历仍保留。
- 状态改为“已接收”或“已发表”时，整篇论文会转入成果板块。

### 6.2 提醒与归档

投稿提醒从 `status_updated_at` 起每 15 天计算。提醒窗口可选择“稍后提醒”或“已处理”，避免同一条记录被反复打扰。

“拒稿归档”位于投稿记录上方，保存论文名和期刊名，便于回顾投递路径；删除/归档前会显示清晰的确认窗口。

### 6.3 成果与 PDF

成果分为论文、专利、奖项和其他。成果可以关联本地 PDF 链接，不会复制 PDF 文件。

在“更新研究画像”时，已链接且可提取文字的 PDF 会分段读取；未变化文件使用本地缓存，避免重复 AI 费用。扫描版 PDF 需要先进行 OCR 才能提供全文文字。

## 7. LIBRARY：期刊库与为论文选刊

### 7.1 期刊库

期刊库会从投稿记录自动吸收期刊，也可手动添加。列表默认按统一后的大出版社分组，期刊名优先占据可读宽度，方向标签会紧凑截断。

- **JCR 分区**：支持手动填写、Clarivate 已核验和 DeepSeek 待核验估计；只有手动/核验结果会参与 Q3/Q4 默认过滤。
- **全部更新缺少/变化期刊**：只处理新增或资料发生变化的期刊；稳定记录会被跳过。
- **优先级**：必看、关注、扩展、不订阅。它会影响前沿排序，但不会压过期刊的实际分区质量。
- 低频操作（收藏、更新资料、删除）收在 `⋯` 中；编辑和移动保留在行内，减少按钮噪音。

### 7.2 为论文选刊（v11.5 AI 决策工作台）

从 PAPERS 或期刊库打开“为论文选刊”，选择已有论文后，系统先按论文**摘要**做主题与期刊方向匹配，再由 AI 生成主推荐。期刊库只用来核对已知分区、OA 和个人经历，不会把 AI 推荐局限在本地已有期刊中。

选刊前可设置要求：

- **出版社**：可限定一个出版社，也可不限。
- **费用**：可选不付费、付费或不限；混合 OA 同时计入不付费和付费，方便按实际投递方式判断。
- **JCR / 中科院分区**：均可多选 1–4 区，分区以 EasyScholar 或已核验资料优先。
- **开放获取（OA）**：可不限、优先 OA 或仅 OA。
- **发表时效**：常规、时效优先、尽快见刊；越着急，AI 对预计审稿和录用周期的加分越明显。

AI 会给出至少 5 本推荐期刊，每本显示 **AI 总分和推荐理由**。AI 也可以推荐**不在本地期刊库**的期刊；对满意的外部期刊，可直接点击“快速入库”加入期刊库，方便以后跟踪。确认“加入投稿路径”后，才会为该论文新增一条独立的“准备投稿”期刊经历。

## 8. 每日前沿：研究画像、评分与反馈

### 8.1 研究画像

研究画像不再区分固定的一/二级关键词，而是由一组带权重的词组成。

- 锁定的词固定为最高权重 `100`，AI 不会覆盖。
- AI 新增的无充分证据词会进入“待确认”，不会直接参与检索。
- 排除词永远不与活跃词并存。
- 成果/PDF 和你的前沿反馈发生变化时，才会触发一次 AI 画像校准；未变化内容会跳过。

### 8.2 入选与排序

论文至少需要命中 **两个不同的活跃词** 才会入选。优先使用作者关键词；没有作者关键词时才使用标题和摘要。

总分由以下可见部分相加，本地总分为 0-100：

| 项目 | 分值 |
| --- | ---: |
| 命中的研究画像词 | 对应词权重之和 |
| 期刊优先级：必看 / 关注 / 扩展 | 50 / 35 / 15 |
| 已核验或手动 JCR：Q1 / Q2 | 50 / 20 |
| 本地反馈 | -30 到 +30 |
| AI 复核 | -15 到 +15 |

已核验或手动标记为 Q3/Q4 的期刊默认过滤；“分区未知”会正常推送，AI 估计仅显示为待核验，不会硬过滤。可在研究设置中关闭 Q3/Q4 过滤。配置了 EasyScholar 密钥后，分区数据以 EasyScholar 更新的 JCR/中科院分区为准，密钥可用时每日前沿直接不再推荐三四区文章。

### 8.3 反馈

每张前沿卡片可：打开原文、加入待读、标为灵感、不相关、写一句话评价、导入其期刊到期刊库。

一句话评价会留下审计事件，并可被下一次画像校准参考；例如“这本是三四区”只标记期刊质量，不会错误降低你的研究主题权重。

## 9. 设置、快捷键与数据

设置被分为五类：外观与工作方式、窗口与导航、提醒与快捷操作、智能增强与 JCR、数据与备份。

- **配色**：共 12 套主题，含 6 套基础色（雾青蓝默认、墨白、苔纸绿、暖砂、石墨雾、夜海）与 6 套双色/强调色主题（朱砂米、紫藤暮、夜航朱、朝霞青、极光夜、鸢尾橙阳）；支持舒适/紧凑信息密度，切换即时预览，取消会恢复原配色。主题与窗口重建已做性能优化，切换和保存不再卡顿。
- **显示/隐藏**：默认在任意前台软件中双击空格即可显示或隐藏；中文输入法开启时自动禁用。也可改为全局组合键或关闭。
- **导入期刊库**：默认全局双击 Tab；可改为带 Ctrl/Alt/Shift/Win 的组合键。
- **开机自启动**：登录 Windows 后直接打开主窗口，而不是自动隐藏到托盘。
- **DeepSeek / Clarivate / EasyScholar**：密钥只保存在本机设置中（EasyScholar 密钥使用系统凭据保护）。DeepSeek 用于画像更新、前沿复核、期刊补全和 AI 选刊；Clarivate 用于 JCR 核验；EasyScholar 用于更新 JCR 分区、中科院分区等期刊信息，密钥来自 [EasyScholar 开放平台](https://www.easyscholar.cc/console/user/open)。
- **备份与迁移**：可立即备份、恢复备份、迁移数据路径或导入旧版 data。迁移前后会保留可恢复副本。

## 10. 升级与故障排查

### 安装升级

使用新的 `科研助手-v11.5.1-安装包.exe` 覆盖安装时，请不要修改默认安装目录。安装器会自动沿用已有目录，不会覆盖 `data`。

升级前仍建议在设置中执行一次“立即备份”。若改过数据路径，也请备份该外部目录。

### 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 双击程序没有出现新窗口 | 软件可能已在运行；会唤醒现有实例。可使用双击空格或托盘图标恢复。 |
| 双击空格不工作 | 检查中文输入法是否开启；或在设置中改为自定义全局组合键。 |
| 下拉框文字看不清 | 在设置中切换主题后重开；v11 的弹窗、菜单和下拉列表使用同一主题。 |
| 前沿结果少 | 检查研究画像锁定词、排除词、数据源和 Q3/Q4 过滤设置；未知分区不会被默认过滤。 |
| AI 补全失败 | 本地功能不受影响。检查 DeepSeek 地址、模型、密钥与网络后重试。 |
| PDF 没有被读到 | 确认链接路径仍存在；扫描版 PDF 先做 OCR。 |

## 11. 建议的日常节奏

1. 打开 HOME，先处理“今日下一步”和红色最近节点。
2. 在 WORK 写下当天 3–5 项关键任务，给真正紧急的重要任务标四象限。
3. 在 PAPERS 更新正在投的期刊状态和回复截止日。
4. 每日或每周查看 LIBRARY 的每日简报，把有价值的论文转为待读或灵感。
5. 每月在期刊库更新经验、检查备份，并让研究画像只吸收你确认过的内容。
