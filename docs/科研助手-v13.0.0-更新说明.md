# 科研助手 v13.0.0 更新说明

## 本次更新解决什么

13.0.0 重点重构每日前沿、特刊发现和为论文选刊，统一采用“召回 → 事实初筛 → 规则双轴评分 → 可选 AI 有限调整 → 动态展示”的流程。低相关或资料暂缺不再等同于删除；只有事实性无效、客观不可能或用户明确永久排除才硬删除。

## 每日前沿

- 六个核心来源：OpenAlex、Crossref、Semantic Scholar、Europe PMC、DOAJ、arXiv。
- 六种召回：关键词、语义相似、引用网络、确认作者、完整期刊库、主题扩展。
- 相关度与科研价值两轴各由 66 分本地规则和最多 34 分 AI 调整组成；AI 未配置或失败时按规则分归一化，不写入 0 分占位。
- 所有通过硬门槛的内容按动态 A/B/C 展示，不限定每日最多或最少篇数；当天无正常层级时只允许不突破硬门槛的逐级回补。
- “保留未读”开启时，前一日未读继续留在同一页面；关闭时移除内容但保留去重指纹。

## 特刊发现

- 六个官网来源独立运行并记录健康状态；第三方来源保留原始证据、抓取时间和许可证来源。
- Elsevier 官网目录不可解析时会实际启用只读备用入口；Wiley 先按研究方向定位真实期刊，再访问该刊当前官方征稿页。
- 标题、期刊/出版社、主题范围、链接、截止日期或 rolling 状态、方向相关度和双轴有效分均为展示硬门槛。
- 第三方记录在官网暂时无法核验时可标注“官网暂未核验”后展示；出版社加分必须先完成期刊身份归一。
- 合格的 Elsevier、Springer Nature、Wiley、Taylor & Francis 特刊优先可见；没有合格结果时不以 MDPI、Frontiers 或其他低质量记录补数量。

## 为论文选刊

- 候选同时来自相似论文的真实发表期刊和完整本地期刊库。
- 论文—期刊契合度、投稿策略可行性分别评分，形成冲刺、主投、稳妥、探索动态分层。
- 期刊确认停刊、确认不接受文章类型、已核验 JCR Q3/Q4 或用户永久排除时从当前选刊结果排除；分区、周期、费用或身份未知时仍保留在期刊库和候选证据中。
- 用户主动设置 JCR 或中科院分区条件时作为当前选刊的严格硬门槛；未知分区不会假装满足条件，也不会因此从期刊库永久删除。

## 可靠性、隐私与数据

- 开机自启使用 Windows 任务计划程序并执行真实非界面启动探针；失败时回退当前用户启动项。
- 更新任务支持错过补跑、成功不重跑、部分失败只补失败来源，以及分阶段检查点和崩溃后幂等续跑。
- API Key 使用当前 Windows 用户加密保护；所有可配置接口集中到设置。
- EasyScholar 只有在已启用、已保存且密钥可由当前 Windows 用户成功解密时才显示就绪；旧密钥无法解密时会明确提示重新填写。
- 每日前沿与特刊工作台不再保留旧版 Pending 按钮、筛选项或标签页；待补全记录仅在内部候选池继续补证据。
- AI 可在用户允许时按当前任务检索相关笔记、PDF、投稿和审稿记录；默认项目隔离、过滤无关个人信息，并保存不含原文和密钥的资料使用清单。
- v13 迁移前自动创建可校验备份，迁移失败不覆盖旧数据。
