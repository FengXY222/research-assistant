# 科研助手 v13.1.3 更新说明

## 启动卡顿修复

- 正式数据已达约 758 MB，旧启动流程会在窗口出现前同步导入所有页面模块，并执行当日备份，冷启动可持续 8–13 秒。
- 现在先显示可响应的启动进度窗口，只建立窗口骨架和概览页；任务、投稿、灵感、期刊、每日前沿、特刊与成果页在首次打开时后台导入并原位替换。
- 页面准备期间先显示轻量占位，导航操作立即返回，避免 Windows 将程序标记为“未响应”。
- 每日备份彻底移出启动流程：仅当软件不在前台使用且空闲计时达到条件后，才在低优先级独立线程中执行。
- 每日前沿、期刊增强与特刊检查也进入空闲任务队列；用户回到软件时，尚未开始的后台任务自动继续延期。
- 开机启动探针只检查可执行文件、数据目录、单实例内存和本地通信，不再导入整套页面。

## 兼容性

- 未修改每日前沿、期刊库、特刊征稿、选刊、评分、去重、续跑和 API 调用规则。
- 不修改正式数据格式，不删除现有记录、备份、密钥或去重指纹。

- 自动化测试：659 项通过（为隔离 Qt 全局界面状态，按模块分批运行）。
- 轻量正式数据副本：主窗口模块导入约 0.13 秒，概览页构建约 0.13 秒；启动时仅加载概览页。
- 七个延迟页面：导航调用约 1–95 毫秒内返回，页面后台准备约 40–472 毫秒完成。
- 打包版启动探针：通过，退出码为 0。
- 打包版完整启动：1.5 秒和 8 秒检查均正常响应；独立空白数据目录下工作集约 80 MB。
- 动态页面打包检查：七个延迟页面模块均已进入可执行文件归档。
