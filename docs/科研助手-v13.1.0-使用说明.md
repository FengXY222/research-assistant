# 科研助手 v13.1.0 使用说明

科研助手是本地 Windows 科研小组件，只保留小组件模式。主界面仍由四个工作台组成：概览、工作、论文、文献；大型选刊、研究画像和特刊征稿在独立窗口中完成。

## 1. 导航和界面

- 左侧“概览 / 工作 / 论文 / 文献”是四个工作台，图标与中文横排显示。
- 工作台顶部的标签用于切换组内页面，例如文献工作台包含“每日前沿 / 期刊库 / 特刊征稿”。
- 每页彩色页头只保留一个主操作；历史、导入、研究设置、AI 复核等次要动作在“…”菜单中。
- 程序只使用“雾青蓝”主题；可在设置中心的“外观”调整舒适或紧凑密度。

## 2. 四个工作台

### 概览

首页围绕“今日下一步”组织今日任务、投稿推进、每日前沿和知识记录。这里用于快速查看，不替代各功能页的完整编辑。

### 工作

“今日任务”支持添加、循环、四象限优先级和历史；“灵感与待读”保存研究灵感、待读论文以及扫描版 PDF 相关资料。

### 论文

“投稿记录”保存每篇论文的完整投稿经历，并可从页头发起“为论文选刊”；“成果”管理论文、专利、奖项及其他成果。拒稿归档位于投稿页的“…”菜单。

### 文献

“每日前沿”发现论文，“期刊库”沉淀期刊经验，“特刊征稿”管理仍在征集的专题。每日前沿与特刊均会保留去重指纹，避免重复推送。

## 3. 每日前沿

更新采用六个核心来源和六种召回策略，执行“召回 → 事实初筛 → 双轴评分 → 可选 AI 调整 → 动态展示”。双轴包括内容相关度和科研价值；AI 内容相关性分数只占有限调整权限，未配置 AI 仍能正常推荐。

系统按照当天相对排名形成金字塔；总体价值不足时逐级回补。明显无标题、无稳定来源或有效双轴分的记录不展示，JCR Q3/Q4 按既定规则排除但保留去重指纹。用户可在“…”中进入研究画像，也可保留低权重探索。

## 4. 特刊征稿

特刊来源包含出版社官网和经验证的第三方发现源。四大出版社的合格特刊优先可见，但不会用无关内容凑数。第三方发现且官网暂未核验的相关记录会明确标注，供用户人工验证。

刷新先加载当前月、未来两个月和 rolling 分片；部分失败只补失败来源，逐分片提交且分片内可取消。缺少完整征稿范围时可依据标题与其他信息推断主题。

## 5. 为论文选刊

选刊从期刊库和相似论文召回候选，经过事实硬门槛后，按契合度与投稿策略双轴评分，动态形成冲刺、主投、稳妥和探索层。明确停刊、文章类型客观不符、已拒稿或用户永久排除才硬删除；未知信息通常降低置信度而不是直接排除。

## 6. 设置中心

设置中心分为五区：

1. 外观：信息密度。
2. 通用与数据：开机自启、仅最小化不退出、透明度、置顶、快捷键、提醒、备份与数据位置。
3. AI 服务：DeepSeek、Clarivate、EasyScholar，以及论文和特刊来源接口。
4. 研究画像：主题词、来源、每日前沿策略和期刊排序。
5. 期刊工具：元数据补全、出版社校验、JCR/EasyScholar 更新和 AI 补全。

所有可配置 Key 的来源均从 AI 服务进入；密钥在本机加密保存。不可解密的 EasyScholar 密钥会提示重新填写。所有外部 API 共用每秒最多 5 次的限速。

## 7. 可靠运行与数据

程序支持开机自启真实探针、错过即补跑、成功不重跑、部分失败只补失败来源、分阶段检查点和崩溃后幂等续跑。正式数据默认位于 `%LOCALAPPDATA%\科研助手\UserData`，升级或卸载不会主动删除个人数据。
