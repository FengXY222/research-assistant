# 科研助手 v13.1.2 更新说明

## 设置界面

- 设置只保留“通用设置”与“增强服务”两个一级入口，打开后直接编辑完整表单。
- 外观密度并入通用设置；DeepSeek、Clarivate JCR、EasyScholar 和所有论文/特刊来源接口集中到“增强服务”。
- 研究画像仍从每日前沿直接打开，不再在全局设置中重复出现。
- 删除设置中的“期刊工具”分区。

## 页面减法

- 每日前沿删除“切换列表”及其八个子项，页面只保留研究设置、画像更新/撤销和 AI 复核。
- 期刊库删除“数据工具”、土地科学目录补充、批量更新、联网补全和模糊出版社校验等冗余菜单项。
- “新增期刊”改为期刊库顶部的一级“新增”按钮。
- 保留 Clarivate JCR 核验、EasyScholar 指标更新和 DeepSeek 补全三个明确的手动增强操作。

## 性能与稳定性

- 期刊库搜索采用延迟合并，连续输入时不再每个字都重建全部卡片。
- 期刊使用统计改为索引复用，页面只在数据真正变化时刷新。
- 特刊概览与工作台改为按需读取，避免在主窗口启动时复制全部记录。
- 过大的运行检查点会自动压缩，只保留续跑所需的索引、失败来源和去重指纹。

## 数据安全

- 升级安装继续使用原安装目录，不删除 `%LOCALAPPDATA%\科研助手\UserData` 中的个人数据。
- 现有的研究画像、论文、期刊、特刊、投稿、标记、缓存和密钥配置保持兼容。
