# 每日前沿切换与期刊偏好分设计

## 已确认目标

- 从“待审”返回“期刊论文”或“前沿预印本”时立即退出待审筛选，不再重复重建整批待审卡片。
- 历史、待审和排除记录按批显示，默认每批 24 篇，并提供继续加载入口。
- 恢复独立的“期刊偏好分”，但不改变内容最低线和 EasyScholar JCR 一二区准入门槛。
- 小组件卡片同时显示综合分、内容分和期刊分。

## 排序规则

- 期刊论文默认综合分：`AI 内容分 75% + 期刊偏好分 25%`。
- 可在研究设置中把期刊权重调整到 0%-50%；剩余权重自动归给内容分。
- 低权重探索论文在合成后继续应用原有探索系数。
- 预印本没有期刊分，直接按内容分和探索系数排序。
- 期刊库外或尚未评分的期刊使用可配置默认分，默认 50 分。
- 旧“必看 / 关注 / 扩展 / 不订阅”自动映射为 `100 / 80 / 60 / 50`，不破坏既有数据。

## 设置界面

- “每日前沿质量边界”中显示期刊权重滑杆、默认期刊分和当前评分摘要。
- “管理期刊分”打开紧凑表格，可搜索，并按全部、已评分、未评分、JCR Q1、JCR Q2 筛选。
- 每行显示期刊名、JCR/中科院信息、旧优先级和 0-100 分步进框。
- 保存期刊评分后窗口保持在研究设置中，摘要即时更新。

## 卡顿处理

- 页签切换只触发一次渲染。
- 如果当前处于待内容复核、分区待核验或已排除候选，切换主流时恢复上一次普通筛选；没有历史值时回到“今日推荐”。
- 长列表首批只构建 24 张卡片，避免一次创建近百个复杂 Qt 控件。
