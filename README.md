# 科研助手 v13.1.3

## v13.1.3

- 修复大数据库启动时“打开即卡死”：启动只建立窗口骨架和概览页，其余七个页面在首次打开时后台导入并原位替换。
- 启动期间立即显示可响应的进度窗口，页面软加载时也会先显示轻量占位，不再出现长时间无窗口、无反馈。
- 自动备份、每日前沿、期刊增强和特刊检查统一推迟到软件不在前台使用时运行；备份仍在独立线程完成。
- 开机启动探针不再预先导入全部页面模块，降低自启延迟和误判。

## v13.1.2

- 设置收敛为“通用设置”与“增强服务”两个一级入口，完整表单直接展示，不再需要二次点击。
- 外观并入通用设置；DeepSeek、Clarivate JCR、EasyScholar 和论文/特刊来源接口集中到“增强服务”。
- 研究画像仍由每日前沿直接打开；删除设置中的期刊工具分区与每日前沿的列表切换子菜单。
- 期刊库删除冗余批量数据工具，“新增”改为顶部一级操作；保留 JCR、EasyScholar 和 DeepSeek 的明确手动增强操作。
- 完成期刊库搜索防抖、索引复用、页面按需刷新、特刊摘要按需加载及运行记录紧凑化，降低卡顿与内存占用。

## v13.1.1

- 每日前沿改为“论文优先”：默认仅显示标题、来源、双轴摘要、推荐理由和两个主动作，分区、评分构成、来源与反馈入口按需展开。
- 八种前沿列表视图收进“…”菜单；空状态只保留一句结果，缓存变化直接体现在更新按钮，不再堆叠系统诊断文本。

## v12.0

- **只保留小组件模式**：HOME、WORK、PAPERS、LIBRARY 四个工作台适配窄窗口；选刊、研究设置和特刊征稿在需要时打开独立 1024×768 工作台。
- **共享科研智能核心**：已有论文与锁定词形成长期画像，收藏、忽略、关联、已读和一句话评价形成可衰减的正负信号；每日首次启动自动整理，修改前保留当天唯一快照并可撤销。
- **扫描版 PDF 关键词**：本机逐页 OCR 后由 AI 从正文提取、翻译、合并并调整权重；生效、待确认、排除和永久隐藏名单各自有明确边界，锁定词不会被 AI 改动。
- **每日前沿**：OpenAlex、Semantic Scholar 与 Crossref 的真实论文先去重，再按长期/短期画像和行为信号推荐；期刊论文、待核验论文、前沿预印本分流展示，每篇都说明“为什么推荐”。
- **真实论文驱动选刊**：先从相似论文的真实发表期刊生成候选，AI 只补充可核验身份的库外期刊；已拒稿、停刊、身份不明和重复项淘汰，出版社与已核验分区执行硬条件，费用和速度用于排序。
- **特刊征稿**：LIBRARY 新增特刊小组件和独立工作台，从多个期刊官网与聚合来源发现仍开放的专题征稿，AI 阅读完整范围并匹配综合画像及逐篇论文画像，支持核验、筛选、收藏、忽略、关联论文、加入投稿路径、创建准备任务和截止提醒。
- **12 套主题**：所有主题覆盖小组件、设置、关键词、选刊、每日前沿和特刊工作台；切换主题即时预览并避免重复重建导致卡顿。

## 数据安全

- 正式数据默认位于 `%LOCALAPPDATA%\科研助手\UserData`，也可在设置中迁移到其他目录。
- 安装器使用 `UsePreviousAppDir=yes`，正式数据与程序文件分离；旧安装目录中的 `data` 也继续保留，卸载不会删除个人数据。
- 测试通过 `RESEARCH_ASSISTANT_DATA_DIR` 使用临时目录，不允许把正式数据目录当作测试目录。
- 发布前可运行只读检查：

```powershell
& 'S:\Python\Scripts\python.exe' 'S:\小软件\tools\self_check_v110.py' --data-root 'C:\Users\fxy17\AppData\Local\Programs\科研助手\data' --read-only
```

## 开发与测试

```powershell
# 在项目根目录执行；首次运行会创建独立开发环境。
if (-not (Test-Path -LiteralPath '.\.venv\Scripts\python.exe')) { python -m venv .venv }
$python = '.\.venv\Scripts\python.exe'
& $python -m pip install -r .\requirements-dev.txt
& $python .\main.py

# 自动化界面测试不弹出窗口。
$env:QT_QPA_PLATFORM = 'offscreen'
& $python -m pytest -q .\tests
```

`requirements.txt` 仅包含正式运行所需依赖；`requirements-dev.txt` 额外包含 pytest、PyInstaller 和生成使用手册所需的 python-docx。
