# 科研助手 v12.2.1

## v12.2.1

- 修复特刊工作台左侧长标题和长期刊名撑宽控件、列表项高度不足导致的裁切与重叠；状态、期刊名和核验信息改为稳定的三层布局。
- 特刊新增“我的理解”，个人笔记独立保存，官网征稿范围刷新时不会覆盖。
- 收藏、排除、已读和加入期刊库明确归入“特刊操作”；论文选择只影响关联论文、投稿路径和准备任务。
- 每日前沿研究设置新增“期刊排序”页，可按名称、出版社、JCR 和当前分类筛选，并将当前结果批量设为必看、订阅、探索或不订阅。

## v12.2.0

- 每日前沿增加期刊偏好分工作台：可搜索、筛选并快速设置单刊分数，默认按内容相关性 75% 与期刊偏好 25% 合成排序，比例可在界面调整。
- 每日前沿的今日推荐、待复核和历史视图改为分批加载；切换“待内容复核 → 期刊论文”不再一次创建全部卡片而卡死，操作后保持当前位置。
- 特刊征稿统一完整范围、期刊身份、开放状态和画像匹配的证据规则；来源失败按 15 分钟、1 小时、6 小时退避，程序持续运行时每小时检查是否已满 24 小时。
- 特刊筛选保留信息未知项并放在末尾；关闭或过期征稿不再创建投稿路径和准备任务，但仍可入库、关联、查看及恢复个人状态。
- 特刊工作台的推荐、收藏、待核验、状态变化和已忽略页签全部适配 1024×768；中英文范围、核验依据、取消刷新和反向操作保持在当前窗口完成。
- 个人操作采用事务恢复和通知送达确认，后台刷新不覆盖收藏、忽略、已读、关联及任务状态；数据继续兼容 v10.0 及以后版本。

## v12.1.3

- 每日前沿先按完整画像审查标题和摘要，再核对分区；旧分数、宽泛方法词、缩写和检索命中不能直接放行。
- 保留土壤碳矿物保护、碳铁结合及土壤肥力/健康指数评价；纯矿物学不推。
- 服务滑坡评价的 DEM、地形、水文方法进入低权重探索，相关性合格后排序权重为 0.65。
- 核心主题、已有论文及探索检索分开安排；有核心候选时每日推荐至少一半为核心匹配，无核心结果才使用合格画像探索。
- 未完成内容审查、分区待确认及内容淘汰记录分开存放；原有已读、收藏、待读和隐藏记录保留。
- AI 缓存按论文复用，每次最多新增审查 80 篇；失败或超额候选暂存，不默认给分推送。

## v12.1.1

科研助手是面向个人科研工作的本地 Windows 桌面小组件。它使用 PySide6 和本地文件保存任务、论文、投稿、期刊、研究画像、前沿论文与特刊征稿，不需要自建服务器或数据库。

## v12.0

- **只保留小组件模式**：HOME、WORK、PAPERS、LIBRARY 四个工作台适配窄窗口；选刊、研究设置和特刊征稿在需要时打开独立 1024×768 工作台。
- **共享科研智能核心**：已有论文与锁定词形成长期画像，收藏、忽略、关联、已读和一句话评价形成可衰减的正负信号；每日首次启动自动整理，修改前保留当天唯一快照并可撤销。
- **扫描版 PDF 关键词**：本机逐页 OCR 后由 AI 从正文提取、翻译、合并并调整权重；生效、待确认、排除和永久隐藏名单各自有明确边界，锁定词不会被 AI 改动。
- **每日前沿**：OpenAlex、Semantic Scholar 与 Crossref 的真实论文先去重，再按长期/短期画像和行为信号推荐；期刊论文、待核验论文、前沿预印本分流展示，每篇都说明“为什么推荐”。
- **真实论文驱动选刊**：先从相似论文的真实发表期刊生成候选，AI 只补充可核验身份的库外期刊；已拒稿、停刊、身份不明和重复项淘汰，出版社与已核验分区执行硬条件，费用和速度用于排序。
- **特刊征稿**：LIBRARY 新增特刊小组件和独立工作台，从多个期刊官网与聚合来源发现仍开放的专题征稿，AI 阅读完整范围并匹配综合画像及逐篇论文画像，支持核验、筛选、收藏、忽略、关联论文、加入投稿路径、创建准备任务和截止提醒。
- **12 套主题**：所有主题覆盖小组件、设置、关键词、选刊、每日前沿和特刊工作台；切换主题即时预览并避免重复重建导致卡顿。

## 数据安全

- 正式数据默认位于 `%LOCALAPPDATA%\科研助手\UserData`，也可在设置中迁移到其他目录。
- 安装器使用 `UsePreviousAppDir=yes`，正式数据与程序文件分离；旧安装目录中的 `data` 也继续保留，卸载不会删除个人数据。
- 测试通过 `RESEARCH_ASSISTANT_DATA_DIR` 使用临时目录，不允许把正式数据目录当作测试目录。
- 发布前可运行只读检查：

```powershell
& 'S:\Python\Scripts\python.exe' 'S:\小软件\tools\self_check_v110.py' --data-root 'C:\Users\fxy17\AppData\Local\Programs\科研助手\data' --read-only
```
